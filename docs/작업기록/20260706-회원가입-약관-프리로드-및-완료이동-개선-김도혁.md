# 회원가입 약관 프리로드 및 완료 이동 개선

작성: `김도혁`
일자: 2026-07-06

## 선행 작업 및 후속 개선 관계

본 작업은 박소유가 진행한 [회원가입 완료 후 로그인 페이지 자동 이동](./20260706-회원가입-완료후-로그인-이동.md)의 후속 개선 작업이다.

선행 작업에서는 회원가입 성공 후 사용자가 직접 로그인 페이지로 이동해야 했던 문제를 해결하기 위해, 성공 메시지를 2초간 표시한 뒤 `/login`으로 자동 이동하도록 구현했다. 이번 후속 작업에서는 해당 흐름을 다시 검토하여 다음과 같이 개선했다.

- 하드코딩된 2초 대기 시간을 제거했다.
- 로그인 페이지 대신 메인 페이지로 즉시 이동하도록 변경했다.
- `router.push` 대신 `router.replace`를 사용해 완료된 회원가입 화면으로 되돌아가는 흐름을 줄였다.
- 회원가입 약관 모달의 Notion CMS 로딩도 페이지 진입 시점의 비동기 선로딩 방식으로 개선했다.

## 1. 배경

- 필수 약관은 약관 모달이 열린 뒤에야 Notion CMS 조회를 시작해 사용자가 로딩을 기다려야 했다.
- 전체 동의 시 `terms`, `privacy`, `age` 모달이 순서대로 열리면서 약관별 로딩이 반복될 수 있었다.
- 회원가입 성공 후 2초가 지나야 로그인 페이지로 이동하는 흐름을 메인 페이지 즉시 이동으로 개선할 필요가 있었다.

## 2. 원인

- `TermsModal`의 `useEffect`가 모달 마운트 이후 `/api/terms` 요청을 시작하고 있었다.
- 회원가입 성공 처리에 `setTimeout(() => router.push("/login"), 2000)`이 하드코딩되어 있었다.

## 3. 개선 사항

### 3.1 약관 콘텐츠 선로딩

- `useSignupTerms` 훅을 추가해 회원가입 페이지 진입 즉시 `terms`, `privacy`, `age` 콘텐츠를 병렬로 요청한다.
- `locale:type` 키 기반의 진행 중 Promise 캐시로 동일 요청의 중복 실행을 방지한다.
- 약관별 로딩 상태를 독립적으로 관리해 하나의 요청 실패가 다른 약관을 막지 않도록 했다.
- 응답의 `content` 타입을 검사하고 locale별 리소스를 분리했다.

### 3.2 약관 모달 개선

- `TermsModal`의 자체 API 호출을 제거하고 선로딩된 리소스를 전달받아 표시하도록 변경했다.
- 선로딩 완료 후 모달을 열면 별도 로딩 없이 콘텐츠를 즉시 표시한다.
- 실패한 약관만 다시 요청할 수 있도록 재시도 기능을 추가했다.
- 한국어, 영어, 필리핀어 재시도 문구를 추가했다.
- 기존 스크롤 확인 및 동의 조건은 유지했다.

### 3.3 회원가입 완료 후 이동 개선

- 기존 2초 `setTimeout`을 제거했다.
- 회원가입 성공 즉시 `router.replace("/main")`으로 메인 페이지에 이동하도록 변경했다.
- `replace`를 사용해 뒤로가기로 완료된 회원가입 폼에 다시 진입하는 흐름을 줄였다.

## 5. 기대 효과

- 회원 정보를 입력하는 동안 약관을 미리 불러와 모달의 체감 대기 시간을 줄인다.
- 전체 동의 과정에서 다음 약관으로 이동할 때 반복되는 로딩을 줄인다.
- 약관 일부가 실패해도 성공한 약관은 정상적으로 표시한다.
- 회원가입 성공 후 로그인 페이지를 경유하지 않고 메인 페이지로 즉시 이동한다.
