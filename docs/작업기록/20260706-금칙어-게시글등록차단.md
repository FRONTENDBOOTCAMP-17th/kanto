# 금칙어 규칙 기반 게시글 등록 차단

작성: `박소유`
일자: 2026-07-06
근거 커밋: -

## 1. 배경

어드민 콘텐츠 관리에서 금칙어 룰을 등록할 때 "영향받는 기존 게시물" 섹션이 불필요하게 포함되어 있었고, 실제로 사용자가 게시글을 등록할 때 금칙어 룰이 적용되지 않아 위반 게시글이 그대로 등록되는 문제가 있었다.

## 2. 처리

### 2-1. 영향받는 기존 게시물 섹션 제거

`ProfanityForm.tsx`에서 금칙어 룰 등록/수정 폼의 "영향받는 기존 게시물" 섹션 전체를 제거했다. 관련된 `searchMutation`, `affectedPosts`, `searched` 변수 및 `Search`, `FileText` 아이콘 import도 함께 정리했다.

### 2-2. 금칙어 체크 API 신규 생성

`GET /api/admin/profanity-rules/check?text=...` 엔드포인트를 추가했다.
- `profanity_rules` 테이블에서 scope에 `"post"`가 포함된 룰만 조회
- 전달된 텍스트에 금칙어가 하나라도 포함되면 `{ blocked: true }` 반환
- API 오류 시 `{ blocked: false }` 반환하여 서비스 가용성 우선

### 2-3. 게시글 등록 시 금칙어 검사 및 차단

구인구직, 렌탈, 중고거래 세 곳 모두 등록/수정 submit 시 금칙어 API를 호출한다. 위반 시 DB insert 없이 Toast 알림("부적절한 텍스트가 포함되었습니다")만 표시하고 등록을 막는다.

- 구인구직: 1단계(다음 버튼) 에서 제목·주요업무 검사, 2단계(등록하기) 에서 전체 텍스트 재검사
- 렌탈: submit 시 제목·설명 검사
- 중고거래: submit 시 제목·내용 검사

Toast는 기존 `Toast` 공통 컴포넌트(`type="error"`)를 사용했다.
