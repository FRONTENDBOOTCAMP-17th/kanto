# 운영관리 공지 카드에서 점검 기능 언급 제거

작성: `박소유`
일자: 2026-07-06
근거 커밋: -

## 1. 배경

초기 기획에 서비스 점검 일정 관리 기능이 포함되어 있었으나 개발 과정에서 제거되었다. `maintenance/page.tsx`는 API 연결 없이 목데이터(`MOCK_WINDOWS`)만 있는 미구현 상태였고, 실제 API 라우트도 존재하지 않는다. 그러나 운영관리 메인의 카드 레이블이 "공지 & 점검"으로 남아 있어 없는 기능을 노출하고 있었다.

## 2. 처리

운영관리 메인 카드의 레이블과 설명에서 점검 관련 내용을 제거했다.

- label: `"공지 & 점검"` → `"공지 관리"`
- description: `"전체 공지 등록·관리 및 서비스 점검 일정을 설정합니다."` → `"전체 공지를 등록·관리합니다."`

## 3. 변경 파일

| 파일 | 변경 내용 |
|---|---|
| `src/app/(admin)/admin/operation/page.tsx` | 공지 카드 label·description 수정 |
