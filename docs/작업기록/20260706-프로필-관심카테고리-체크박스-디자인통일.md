# 프로필 관심 카테고리 체크박스 디자인 통일

작성: `박소유`
일자: 2026-07-06
근거 커밋: -

## 1. 배경

내 프로필 > 알림 설정 > 관심 카테고리의 체크박스가 회원가입 약관 동의 체크박스와 디자인이 달라 일관성이 없었다.

## 2. 원인

| 위치 | 사용 방식 |
|---|---|
| 프로필 관심 카테고리 | native `<input type="checkbox">` + `accent-teal-500` |
| 회원가입 약관 동의 | shadcn `<Checkbox>` 컴포넌트 |

## 3. 처리

`ProfileAlertsSection`에서 native input을 shadcn `Checkbox` 컴포넌트로 교체하고, 회원가입과 동일한 className을 적용했다.

- `onChange` → `onCheckedChange` 로 변경 (shadcn Checkbox API)
- className: `h-4.5 w-4.5 shrink-0 border-gray-300 bg-white data-checked:border-gray-300 data-checked:bg-white data-checked:text-gray-900`
