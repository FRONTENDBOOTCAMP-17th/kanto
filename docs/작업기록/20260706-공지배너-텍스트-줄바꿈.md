# 공지 배너 긴 텍스트 줄바꿈 처리 (데스크탑)

작성: `박소유`
일자: 2026-07-06
근거 커밋: -

## 1. 배경

데스크탑에서 공지 제목이 길 경우 `하루 안보기` 버튼에 텍스트가 가려지고 한 줄로 잘렸다.

## 2. 원인

- 텍스트에 `line-clamp-1`이 적용되어 강제 1줄 처리
- `하루 안보기` + 닫기 버튼 영역이 `absolute right-0`으로 텍스트 위에 겹침

## 3. 처리

`UnifiedBanner.tsx`의 데스크탑 배너 영역을 수정했다.

- `line-clamp-1` 제거 → 텍스트 자연스럽게 줄바꿈
- `absolute right-0` / `absolute left-0` → `shrink-0` 일반 flex 아이템으로 변경 (겹침 제거)
- `items-center` → `items-start` 로 멀티라인 상단 정렬

| 파일 | 변경 내용 |
|---|---|
| `src/components/common/UnifiedBanner.tsx` | 데스크탑 배너 flex 구조 개선 및 line-clamp 제거 |
