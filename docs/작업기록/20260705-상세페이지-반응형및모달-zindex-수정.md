# 상세 페이지 반응형 레이아웃 및 모달 z-index 수정

작성: `박소유`, `임태형`
일자: 2026-07-05 ~ 2026-07-06
근거 커밋: `3d26eb5`, `f55269e`, `ad4c801`

## 1. 배경

README 스크린샷 정리와 함께 상세 페이지를 모바일·태블릿·데스크탑에서 다시 확인했다. 이 과정에서 구인/렌탈/중고거래 상세의 2열 전환 시점이 빠르고, 일부 모달이 카드 뱃지나 이미지 인디케이터보다 뒤에 깔리는 문제가 발견됐다.

## 2. 상세 페이지 2열 전환 시점 조정

**문제:** `md:flex-row` 기준으로 정보 영역과 사이드 영역을 나누면 태블릿 폭에서 내용이 좁아지고 줄바꿈이 과도하게 발생했다.

**처리:**
- 구인 상세의 정보/지도 영역 전환 기준을 `md`에서 `lg`로 변경
- 렌탈 상세의 정보/지도 영역 전환 기준도 `lg`로 변경
- 중고거래 상세의 판매자/채팅 영역 역시 `lg`부터 가로 배치되도록 조정

**변경 파일:**
- `src/app/(user)/job/[id]/page.tsx`
- `src/app/(user)/rental/[id]/_components/AccommondationInfo.tsx`
- `src/app/(user)/usedgoods/[id]/_components/UsedGoodsDetail.tsx`

## 3. 상세 이미지 영역 정리

**문제:** 이미지 캐러셀을 감싸는 래퍼의 `aspect-4/3`, `items-start/items-stretch` 조합이 페이지별로 달라 높이와 정렬이 어색했다.

**처리:**
- 구인 상세에서는 불필요한 이미지 래퍼를 제거하고 `ImageCarousel` 자체 레이아웃을 사용
- 중고거래 상세에서는 판매 완료 오버레이를 유지하면서 캐러셀 래퍼를 단순화
- 중고거래 위치 지도는 좌측 이미지 높이와 우측 정보 흐름 사이에서 자연스럽게 내려가도록 `mt-auto` 영역에 배치

**변경 파일:**
- `src/app/(user)/job/[id]/page.tsx`
- `src/app/(user)/usedgoods/[id]/_components/UsedGoodsDetail.tsx`

## 4. 채팅 결제 카드 시간 만료 표시 개선

**문제:** 결제 카드의 pending 만료 여부가 `Date.now()` 계산에만 의존해 렌더 이후 시간이 지나도 자동 갱신되지 않았다.

**처리:**
- `transaction.status === "pending"`인 동안 1분 간격으로 `now` 상태를 갱신
- 24시간 경과 여부가 화면에 자연스럽게 반영되도록 수정

**변경 파일:**
- `src/components/common/chat/chatPanel/room/PaymentCard.tsx`

## 5. 본인인증/글쓰기 확인 모달 z-index 수정

**문제:** 본인인증 모달이 카드 뱃지, 좋아요 버튼, 이미지 인디케이터 아래에 가려지는 경우가 있었다. 모달이 특정 컴포넌트 트리 내부에 렌더링되어 부모 stacking context의 영향을 받는 것이 원인이었다.

**처리:**
- `IdentityVerificationModal`을 `createPortal(..., document.body)`로 렌더링
- `CategoryWriteButton`의 본인인증 확인 모달도 `document.body` 포털로 이동
- 기존 `fixed inset-0 z-[100]` 레이어가 실제 최상위 문서 기준으로 적용되도록 보장

**변경 파일:**
- `src/app/(user)/profile/_components/IdentityVerificationModal.tsx`
- `src/components/common/CategoryWriteButton.tsx`

## 6. 검증

- 구인/렌탈/중고거래 상세를 모바일, 태블릿, 데스크탑 폭에서 확인 필요
- 중고거래 판매 완료 오버레이가 이미지 영역 위에 정상 표시되는지 확인 필요
- 본인인증 모달이 목록 카드 뱃지와 이미지 인디케이터보다 위에 뜨는지 확인 필요
- 결제 pending 카드가 24시간 경과 후 별도 새로고침 없이 만료 상태로 전환되는지 확인 필요
