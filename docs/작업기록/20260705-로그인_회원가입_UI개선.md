# 2026-07-05 작업 기록

로그인·회원가입 페이지 UI 개편 세션 요약. 참고 이미지(Glide 등) 기반으로 데스크탑 스플릿 레이아웃 도입, 인풋 스타일 변경, 좌측 패널 애니메이션 추가.

---

## 1. 데스크탑 스플릿 레이아웃 도입
- **배경**: 기존에는 로그인·회원가입 모두 전체 화면 틸 그라데이션 배경 위에 폼 하나만 중앙 배치된 구조. 참고 이미지처럼 데스크탑에서는 브랜드 패널 + 폼을 좌우로 나누고, 모바일에서는 패널 없이 폼만 남는 구조를 요청받음.
- **구현**: `src/app/(user)/_components/AuthHero.tsx` 신규 생성. 로그인·회원가입 페이지가 공유하는 우측(→이후 좌측으로 변경) 브랜드 패널 컴포넌트. `hidden lg:flex`로 1024px 미만에서는 렌더링되지 않음. `lg:sticky lg:h-screen`으로 회원가입처럼 긴 폼에서도 스크롤 시 화면에 고정.
- `src/app/(user)/login/page.tsx`, `src/app/(user)/signup/page.tsx`의 전체 화면 그라데이션 배경을 걷어내고 `flex` 2컬럼 구조(폼 컬럼 `lg:w-120 xl:w-140` 고정폭 + 히어로 `flex-1`)로 교체. 폼 컴포넌트(`LoginForm`, `SignupForm`) 내부는 미변경.
- `messages/{ko,en,fil}.json`에 패널 문구용 `Auth.heroTitle`, `Auth.heroSubtitle` 키 추가.
- **후속 조정**:
  - 데스크탑 좌우 배치를 반대로 변경 요청 → `AuthHero`를 폼 컬럼 앞으로 이동해 "이미지(패널) 좌측 / 폼 우측"으로 전환.
  - "우측 섹션은 흰 배경이어야 한다" 요청 → 확인 결과 실제 의도는 반대(좌측 패널이 흰 배경). 기존 어두운 틸 그라데이션을 흰 배경 + 연한 블러 원 장식 + 우측 구분선(`border-r border-gray-100`)으로 교체, 텍스트 색상도 어두운 톤(`gray-900`/`gray-500`)으로 반전.

## 2. 회원가입 상단 네비게이션 정리
- "< 홈" 링크를 "< 로그인"으로 바꿔달라는 요청 → 이후 "그냥 삭제, 하단에 이미 로그인 링크 있음"으로 정정.
- `src/app/(user)/signup/page.tsx`: 상단 뒤로가기 `Link` 및 `ChevronLeft` import 제거. 언어 전환 버튼(`LanguageSwitcher`)만 우측에 유지.
- 이어서 "로그인 페이지 기준으로 회원가입 레이아웃 통일" 요청 → 컬럼 패딩, 콘텐츠 폭(`max-w-md`), 로고 크기(`w-44 sm:w-48`), 수직 중앙 정렬 구조를 로그인과 동일하게 맞춤.

## 3. 인풋 스타일 변경 — 라벨 제거, 좌측 아이콘, 하단 보더만
- **요청**: 로그인(이메일·비밀번호), 회원가입(이름·이메일·비밀번호·비밀번호 확인) 인풋 위 라벨 텍스트를 없애고 아이콘으로 대체. 아이콘 위치는 참고 이미지 확인 결과 인풋 **좌측**으로 확정(사용자가 우측이라 했으나 참고 사진은 좌측이라 확인 질문 후 좌측으로 결정).
- `src/app/(user)/login/_components/LoginForm.tsx`, `src/app/(user)/signup/_components/SignupForm.tsx`:
  - 라벨(`Label`/`label`) 전부 제거, 각 인풋에 `aria-label`로 접근성 유지.
  - lucide 아이콘(`Mail`, `Lock`, `User`)을 인풋 좌측에 절대 위치로 배치.
  - 인풋 스타일을 둥근 박스(`rounded-xl border`)에서 하단 보더만 있는 언더라인 스타일(`border-0 border-b`)로 변경. 포커스 시 밑줄 틸 색, 에러 시 빨간색 유지.
  - 회원가입 비밀번호 표시(눈) 토글은 우측 끝 위치 유지.

## 4. 좌측 패널 비눗방울 애니메이션
- **요청**: 좌측 이미지(브랜드 패널) 영역에 비눗방울처럼 떠다니는 애니메이션 추가.
- `src/app/globals.css`: `bubbleRise` 키프레임 추가 — 하단에서 상단으로 상승하며 `--bubble-drift` CSS 변수로 개별 좌우 드리프트, 진입·소멸 시 페이드. `.auth-bubble` 클래스에 `prefers-reduced-motion: reduce` 대응(애니메이션 끄고 저투명도 고정) 포함.
- `src/app/(user)/_components/AuthHero.tsx`: 방울 12개를 크기(10~54px)·상승 속도(10~24초)·좌우 위치·드리프트 폭이 제각각인 배열로 정의. 음수 `animation-delay`를 줘서 로드 시점에 이미 서로 다른 높이에 떠 있는 것처럼 보이도록 처리. 방울은 좌상단 하이라이트가 있는 방사형 그라데이션 + 얇은 틸 테두리로 유리질 광택 표현.

- 로그인 페이지 상단 "< 홈" 링크는 그대로 유지됨 — 회원가입과 통일감을 원할 경우 추가 논의 필요.
