## 1. 데스크탑 스플릿 레이아웃 도입
- **배경**: 기존에는 로그인·회원가입 모두 전체 화면 틸 그라데이션 배경 위에 폼 하나만 중앙 배치된 구조. 참고 이미지처럼 데스크탑에서는 브랜드 패널 + 폼을 좌우로 나누고, 모바일에서는 패널 없이 폼만 남는 구조를 요청받음.
- **구현**: `src/app/(user)/_components/AuthHero.tsx` 신규 생성. 로그인·회원가입 페이지가 공유하는 우측(→이후 좌측으로 변경) 브랜드 패널 컴포넌트. `hidden lg:flex`로 1024px 미만에서는 렌더링되지 않음. `lg:sticky lg:h-screen`으로 회원가입처럼 긴 폼에서도 스크롤 시 화면에 고정.
- `src/app/(user)/login/page.tsx`, `src/app/(user)/signup/page.tsx`의 전체 화면 그라데이션 배경을 걷어내고 `flex` 2컬럼 구조(폼 컬럼 `lg:w-120 xl:w-140` 고정폭 + 히어로 `flex-1`)로 교체. 폼 컴포넌트(`LoginForm`, `SignupForm`) 내부는 미변경.
- `messages/{ko,en,fil}.json`에 패널 문구용 `Auth.heroTitle`, `Auth.heroSubtitle` 키 추가.
- **후속 조정**:
  - 데스크탑 좌우 배치를 반대로 변경 요청 → `AuthHero`를 폼 컬럼 앞으로 이동해 "이미지(패널) 좌측 / 폼 우측"으로 전환.
  - "우측 섹션은 흰 배경이어야 한다" 요청 → 확인 결과 실제 의도는 반대(좌측 패널이 흰 배경). 기존 어두운 틸 그라데이션을 흰 배경 + 연한 블러 원 장식 + 우측 구분선(`border-r border-gray-100`)으로 교체, 텍스트 색상도 어두운 톤(`gray-900`/`gray-500`)으로 반전.

## 6. 히어로 텍스트 폰트 변경 + 첫 렌더링 단계적 등장 애니메이션
- **요청**: 히어로 패널 텍스트 폰트 변경, 첫 렌더링 시 제목 1줄 → 2줄 → 설명 순으로 아래에서 위로 올라오며 등장.
- **폰트 선택 경위**: 처음 `Baloo 2`(Google Font)를 `next/font/google`로 적용했으나, 이 폰트는 한글 글리프가 없어 한국어 텍스트에는 적용되지 않는 문제 발견(영문 "Kanto"만 적용됨). 사용자 확인 후 한글을 지원하는 라운드체 `Jua`로 전면 교체.
- `next/font/google`의 이 프로젝트 번들 메타데이터에는 어떤 폰트에도 `korean` 서브셋이 등록돼 있지 않아 최적화 로더 사용 불가 → `AuthHero.tsx`에 `<link rel="stylesheet" href=".../css2?family=Jua&display=swap">`를 직접 렌더링(App Router가 자동으로 `<head>`에 호이스팅). 관련 `@next/next/no-page-custom-font` 린트 경고는 App Router에 `pages/_document.js`가 없어 발생하는 오탐이라 사유를 남기고 `eslint-disable-next-line` 처리.
- `src/app/globals.css`: `.font-jua` 유틸리티 클래스 추가. `heroFadeUp` 키프레임(아래→위 이동 + 페이드) 추가, `.hero-fade-up` 클래스로 적용.
- `messages/{ko,en,fil}.json`: `Auth.heroTitle`을 `heroTitleLine1`/`heroTitleLine2` 두 키로 분리(줄바꿈 지점을 로케일마다 자연스럽게 지정하기 위함).
- `AuthHero.tsx`: 제목 두 줄을 각각 `<span className="hero-fade-up block">`으로 감싸 0ms/150ms 지연, 설명 문단은 350ms 지연으로 순차 등장.

## 7. 히어로 폰트 굵기 조정 (두 차례 되돌림)

## 14. 버튼 rounded·색상 반복 조정 (로그인 스코프 한정)
- **요청**: "버튼들이 전체적으로 너무 rounded" → 로그인 제출 버튼 `rounded-lg`(12번 항목에서 적용)를 `rounded-md`로 한 단계 더 축소. 소셜 로그인 버튼(카카오/구글/페이스북)도 `LoginButton.tsx`에서 `rounded-md`를 추가로 덮어써 통일.
- **색상 반복 조정**: 로그인 제출 버튼을 진한 채움(`bg-teal-400`)에서 여러 차례에 걸쳐 조정 — `bg-teal-100/50` 시도 → 최종적으로 `bg-white` + `border-teal-400`(이후 `border-teal-200`로 더 연하게) + 텍스트는 처음 `text-teal-600` → "회원가입" 링크와 같은 색으로 맞춰달라는 요청에 따라 `text-teal-500`으로 최종 확정.
- 전역 `Button`의 `teal` variant(`bg-teal-500 text-white`)는 헤더·글쓰기·직거래 등록 폼 등 앱 전체에서 재사용되므로 건드리지 않고, 로그인 버튼 인스턴스의 `className`만 twMerge로 덮어쓰는 방식으로 스코프 한정.
- 회원가입 쪽 버튼/뱃지 rounded는 "같은 개념으로" 별도 요청 시점에 일괄 처리(아래 15번).

## 16. 약관 동의 체크박스 — 체크 표시만 별도 색상 지정
- **문제**: 네이티브 `<input type="checkbox" className="accent-teal-500">`는 `accent-color`가 박스 배경과 체크(V) 표시 색을 하나로 묶어서 렌더링하기 때문에, "박스 배경은 그대로 두고 체크 표시만 다른 색"으로 분리 지정이 불가능.
- `AgreeSection.tsx`: 기존 shadcn `Checkbox`(Radix 기반, `src/components/ui/checkbox.tsx`) 컴포넌트로 교체. `data-checked:bg-white data-checked:border-gray-300`로 체크 시에도 박스 배경/테두리를 흰색으로 고정하고, 체크 아이콘 색만 별도 지정(`text-teal-500` → 최종 "검정색이 더 낫다" 피드백에 따라 `text-gray-900`으로 변경).
- `<label>`로 감싸 클릭 시 토글되는 기존 동작은 Radix `Checkbox`도 `<button>`으로 렌더링되어 label의 클릭 위임이 동일하게 작동하므로 그대로 유지됨.

## 17. 필수/선택 뱃지 스타일 반복 조정
- **1차**: 진한 채움(`bg-teal-100 text-teal-700`, `rounded-full`)을 더 모던한 느낌으로 — 옅은 배경 + 얇은 링(`ring-1 ring-inset`) + 대문자·자간(`tracking-wide uppercase`) 스타일로 변경, `rounded-md`로 축소.
- **색상 재검토**: "teal 말고 네이비 등 다른 톤도 많다"는 피드백에 따라 후보(슬레이트/인디고/그레이/앰버)를 제시 → 슬레이트 선택, `bg-teal-50/text-teal-600` → `bg-slate-50 text-slate-600 ring-slate-300`으로 변경(브랜드 teal과 겹치지 않게 "필수"를 구분).
- **최종**: "배경을 강하게, 텍스트를 흰색으로"라는 요청에 따라 "필수" 뱃지를 링 스타일에서 진한 채움으로 재전환 — `bg-slate-700 text-white`. "선택" 뱃지는 기존 옅은 링 스타일(`bg-gray-50 text-gray-400 ring-gray-200`) 유지.

## 후속(미처리)
- 히어로 패널 문구(`heroTitleLine1/2`, `heroSubtitle`)는 임시로 작성한 카피이므로 팀 검수 필요.
