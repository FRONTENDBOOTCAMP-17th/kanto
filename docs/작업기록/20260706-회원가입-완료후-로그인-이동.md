# 회원가입 완료 후 로그인 페이지 자동 이동

작성: `박소유`
일자: 2026-07-06
근거 커밋: `78a0dda`

## 1. 배경

회원가입 성공 시 성공 메시지만 표시되고 페이지 이동이 없어 사용자가 로그인 페이지로 직접 이동해야 했다.

## 2. 원인

`handleSignup`에서 `setIsSuccess(true)` 이후 redirect 코드가 없었다.

## 3. 처리

회원가입 성공 후 2초간 성공 메시지를 보여준 뒤 `/login` 으로 자동 이동하도록 `setTimeout(() => router.push("/login"), 2000)` 추가.

## 4. 변경 파일

| 파일 | 변경 내용 |
|---|---|
| `src/app/(user)/signup/page.tsx` | 회원가입 성공 후 2초 뒤 로그인 페이지로 redirect |
