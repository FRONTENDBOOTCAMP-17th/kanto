# 프로필 알림 설정 댓글 알림 제거

작성: `박소유`
일자: 2026-07-06
근거 커밋: `503fee3`

## 1. 배경

초기 기획에 포함되어 있던 댓글 기능이 개발 과정에서 제거되었으나, 알림 설정의 댓글 알림 토글(`alert_comment`)이 코드에 잔존해 있었다. 실제로 댓글 기능이 없는 상태에서 해당 토글이 노출되는 것은 부적절하여 제거했다.

## 2. 처리

`ProfileAlertsSection.tsx`의 `ALERT_ITEMS` 배열에서 `{ key: "comment", field: "alert_comment" }` 항목을 삭제. `alert_comment` 필드는 DB에 유지되고 UI에서만 숨김.

## 3. 변경 파일

| 파일 | 변경 내용 |
|---|---|
| `src/app/(user)/profile/_components/sections/ProfileAlertsSection.tsx` | ALERT_ITEMS에서 comment 항목 제거 |
