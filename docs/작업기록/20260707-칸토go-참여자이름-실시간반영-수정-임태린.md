# 칸토Go 모임 참여자 이름(아바타) 목록 실시간 미반영 버그 수정

- 작성일: 2026-07-07
- 관련 이슈: #620
- 관련 파일:
  - `src/components/go/MeetupDetailPanel.tsx`

## 1. 증상

칸토Go 모임 상세 패널에서 다른 사용자가 모임에 참여하면, 참여 인원 **숫자와 진행 바(progress bar)는
실시간으로 갱신**되지만 그 하단의 **참여자 이름(성) 아바타 목록은 실시간으로 반영되지 않는다.**
패널을 닫았다가 다시 열어야만 새로 참여한 사람의 아바타가 보인다.

## 2. 근본 원인

숫자/바와 이름 목록이 **서로 다른 데이터 소스**를 쓰는데, realtime 구독은 한쪽에만 걸려 있었다.

- **숫자 + 바**: `meetup.participant_count` prop으로 계산(`MeetupDetailPanel.tsx`).
  이 prop은 `useLiveMeetups.ts`가 `meetup_participants` 테이블의 `postgres_changes`를
  구독해 목록 전체(`getActiveMeetups`)를 재조회하므로 실시간으로 갱신된다.
- **이름 목록**: 로컬 `participants` state로 렌더링. 이 state는 마운트 시
  `getMeetupDetail`로 **한 번만** 채워지고, 그 effect의 의존성이
  `[meetup.post_id, currentUserId]`뿐이라 남이 참여/취소해도 재실행되지 않았다.
  별도의 realtime 구독도 없었다.

```tsx
// 수정 전 — 참여자 목록 fetch가 status 조회와 한 effect에 묶여 있었음
useEffect(() => {
  ...
  getMeetupDetail(meetup.post_id).then(({ participants }) => {
    if (active) setParticipants(participants);
  });
  ...
}, [meetup.post_id, currentUserId]); // 참여자 수 변화와 무관
```

즉 "숫자/바"는 이미 실시간인 prop을 그대로 쓰고, "이름 목록"은 최초 1회 스냅샷에
머물러 있어 둘 사이에 불일치가 발생했다.

## 3. 수정

참여자 목록 fetch를 **별도 effect로 분리**하고, 의존성에 이미 realtime으로 갱신되는
`meetup.participant_count`를 추가했다. 새 구독/채널을 만들지 않고 기존 `getMeetupDetail`을
그대로 재사용한다.

```tsx
useEffect(() => {
  let active = true;

  getMeetupDetail(meetup.post_id)
    .then(({ participants }) => {
      if (active) setParticipants(participants);
    })
    .catch(() => {});

  return () => {
    active = false;
  };
}, [meetup.post_id, meetup.participant_count]);
```

남이 참여 → realtime이 `meetup.participant_count`를 갱신 → 이 effect 재실행 →
`getMeetupDetail` 재조회 → 이름 아바타 목록이 숫자·바와 함께 실시간으로 반영된다.

기존 effect에서는 "내 참여 상태(`myStatusState`)"·신고 여부 조회 로직만 남기고,
의존성은 그대로 `[meetup.post_id, currentUserId]`를 유지했다(참여자 수 변화와 무관한 로직이므로).

**트레이드오프**: 한 명이 나가는 동시에 다른 한 명이 들어와 `participant_count` 총합이
우연히 그대로인 극히 드문 순간은 재조회를 못 놓칠 수 있다. hotfix 범위에서는 영향이
미미해 수용했다.

1. `npx tsc --noEmit` — 통과.

3. **실사용 검증**: 같은 모임 상세 패널을 두 브라우저(또는 시크릿 창)에서 열고, 한쪽에서
   참여 처리 → 다른 쪽 패널에서 숫자·바와 **함께** 참여자 아바타가 실시간으로 추가되는지 확인.
