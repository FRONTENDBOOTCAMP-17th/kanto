# 운영관리 카드 클릭 scale 애니메이션 수정

작성: `박소유`
일자: 2026-07-06
근거 커밋: -

## 1. 배경

어드민 운영관리 페이지에서 카드를 클릭할 때 움직임이 과하게 느껴지는 문제가 있었다.

## 2. 원인

`globals.css`에 전역으로 `button:not(:disabled), a { active:scale-[1.05] }` 가 설정되어 있다.

작은 버튼(높이 36px)에서는 5%가 약 1.8px 차이라 거의 체감되지 않지만, 운영관리 카드는 `min-h-40`(160px 이상) 크기라 같은 5%여도 8px 이상 움직여 훨씬 크게 느껴졌다.

## 3. 처리

전역 값은 건드리지 않고, 운영관리 카드 Link에 `active:scale-[1.01]`을 직접 추가해 전역값을 덮어씌웠다.

## 4. 변경 파일

| 파일 | 변경 내용 |
|---|---|
| `src/app/(admin)/admin/operation/page.tsx` | 카드 Link에 `active:scale-[1.01]` 추가 |

## 5. 결과

운영관리 카드 클릭 시 scale 효과가 1%로 줄어 부자연스러운 움직임이 개선된다.
