# 어드민 글관리 총 개수 수정

작성: `박소유`
일자: 2026-07-06
근거 커밋: `7d7f43d`

## 1. 배경

어드민 글관리 페이지에서 표시되는 "총 N건" 수치가 삭제된 게시글을 제외하고 있어 실제 전체 개수와 달랐다.

## 2. 원인

`totalCount`를 `items.filter((p) => p.status !== "deleted").length`로 계산해 삭제 상태 게시글이 집계에서 빠졌다.

## 3. 처리

`totalCount = items.length`로 변경해 활성 + 삭제 포함 전체 개수를 표시하도록 수정.

|---|---|
| `src/app/(admin)/admin/posts/_components/AdminPostsClient.tsx` | totalCount 집계 시 삭제 게시글 포함 |
