## 1. 배경

관리자 화면 최종 점검 중 모바일 레이아웃, 테이블 말줄임, 드로어 스크롤, 삭제 데이터 노출, 필터 드롭다운 UI가 여러 페이지에서 조금씩 어긋났다. 각 항목은 작은 수정이지만 운영자가 반복해서 보는 화면이므로 한 번에 마감 품질을 정리했다.

## 2. 공통 드로어·사이드바 스크롤 처리

**문제:** 모바일 관리자 사이드바나 상세 드로어가 열린 상태에서 배경 페이지가 함께 스크롤될 수 있었다. 긴 사이드바는 작은 화면에서 자체 스크롤도 필요했다.

**처리:**
- `useBodyScrollLock(open)` 훅을 추가하고 관리자 사이드바/상세 드로어에 적용
- 모바일 사이드바를 `h-dvh`, `overflow-y-auto`로 변경
- 신고/게시글/유저/감사 로그 상세 드로어에도 배경 스크롤 잠금 적용

**변경 파일:**
- `src/hooks/useBodyScrollLock.ts`
- `src/app/(admin)/_components/AdminSidebar.tsx`
- `src/app/(admin)/admin/_components/DashboardReportCenter.tsx`
- `src/app/(admin)/admin/operation/audit-logs/_components/DetailDrawer.tsx`
- `src/app/(admin)/admin/posts/_components/PostDetailDrawer.tsx`
- `src/app/(admin)/admin/reports/_components/ReportsClient.tsx`
- `src/app/(admin)/admin/users/_components/UserDetailDrawer.tsx`

## 3. 대시보드 KPI 숫자 오버플로우 수정

**문제:** KPI 값이 커지면 카드 폭보다 숫자가 길어져 깨질 수 있었다.

**처리:**
- KPI 카드를 container query 기준으로 만들고 `clamp()`로 숫자와 단위 크기를 동적으로 제한
- 값 영역에 `whitespace-nowrap`을 적용해 줄바꿈 대신 카드 내부에서 크기를 조절

**변경 파일:**
- `src/app/(admin)/admin/_components/KpiCards.tsx`

## 4. 글 관리 카드 뱃지 색상 통일

**문제:** 모바일 카드의 게시글 유형 뱃지가 데스크탑 테이블 색상 체계와 달랐다.

**처리:**
- `used_goods`, `jobs`, `rental`별 색상 매핑을 카드에도 적용
- 알 수 없는 유형은 slate fallback 색상 사용

**변경 파일:**
- `src/app/(admin)/admin/posts/_components/AdminPostsCard.tsx`

## 5. 삭제/탈퇴 데이터 숨김

**문제:**
- 유저 상세 게시글 목록에 삭제된 게시글이 남아 보일 수 있었다.
- 신고 내역에서 탈퇴 회원 또는 삭제 게시글 대상 신고가 계속 노출될 수 있었다.

**처리:**
- 유저 상세 게시글 조회에 `status != deleted` 조건 추가
- 신고 목록 구성 시 게시글 대상은 post가 존재하고 `status !== "deleted"`인 경우만 표시
- 유저/메시지 대상 신고는 대상 유저가 존재하고 `deleted_at == null`인 경우만 표시

**변경 파일:**
- `src/services/admin/adminUsers.ts`
- `src/app/(admin)/admin/reports/page.tsx`

## 6. 결제·채팅·번개모임 테이블 말줄임 처리

**문제:** 게시글 제목, 구매자/판매자 이름, 채팅 기록, 번개모임 제목 등이 긴 경우 관리자 테이블과 드로어가 깨졌다.

**처리:**
- 결제 내역 테이블 제목/이름에 `truncate`, `max-w-*`, `whitespace-nowrap` 적용
- 채팅 관리 드로어의 메시지/게시글 정보 영역을 말줄임 중심으로 재정리하고 하단 닫기 버튼 제거
- 번개모임 관리자 테이블에서 긴 텍스트가 셀을 밀지 않도록 폭과 말줄임 조정
- 번개모임 목록은 최신 생성순으로 정렬되도록 서비스 조회 기준 보정

**변경 파일:**
- `src/app/(admin)/admin/payments/_components/AdminPaymentsClient.tsx`
- `src/app/(admin)/admin/chats/_components/SearchChat.tsx`
- `src/app/(admin)/admin/go/page.tsx`
- `src/services/go/go.ts`

## 7. 운영 관리 하위 페이지 모바일 레이아웃 수정

- 좁은 화면에서 컨트롤이 부모 폭을 밀지 않도록 `min-w-0`, `w-full`, breakpoint 기준을 정리

## 8. 감사 로그 드롭다운 UI 통일

**문제:** 감사 로그의 액션 필터, 대상 필터, 날짜 필터가 서로 다른 UI 패턴을 사용했다. 특히 대상 필터는 native select라 나머지 필터와 시각적/동작적 일관성이 부족했다.

**처리:**
- 공통 `FilterDropdown` 컴포넌트로 액션/대상/날짜 필터를 통일
- `useClickOutside`로 외부 클릭 시 닫힘 처리
- 패널이 화면 오른쪽을 넘칠 경우 오른쪽 정렬로 전환
- 대상 필터도 custom dropdown으로 변경
- 감사 로그 테이블에 `overflow-x-auto`, `min-w-*`를 적용해 좁은 화면에서 깨짐 방지

**변경 파일:**
- `src/app/(admin)/admin/operation/audit-logs/_components/AuditLogsClient.tsx`
- `src/app/(admin)/admin/operation/audit-logs/_components/ActionBadge.tsx`
- `src/app/(admin)/admin/operation/audit-logs/_components/useAuditFilters.ts`
