# 스크롤 컨테이너 패턴 도입 — 드롭다운 레이아웃 시프트 수정

## 문제

Radix UI Select(드롭다운)를 열면 화면이 왼쪽으로 밀리는 현상 발생.

**원인**: `react-remove-scroll`이 Select 열릴 때 `body[data-scroll-locked] { margin-right: Xpx !important }`를 주입함.
gap = `window.innerWidth - document.documentElement.clientWidth` (스크롤바 너비). 스크롤바가 사라질 때 이 값이 >0이 되어 body가 오른쪽으로 밀림.

## 근본 해결: 스크롤 컨테이너 패턴

`html/body`를 `overflow: hidden`으로 고정 → 브라우저 레벨 스크롤바가 아예 사라짐 → gap = 0 → `react-remove-scroll`이 `margin-right: 0` 주입 → 레이아웃 시프트 없음.

대신 내부 div(`#scroll-root`)가 실제 스크롤을 담당 (`overflow-y: auto`).

## 변경된 파일

### 신규
- `src/contexts/ScrollContext.tsx` — `ScrollContext` (React context) + `useScrollContainer()` hook 제공. 스크롤 컨테이너 div의 ref를 컴포넌트 트리 전체에 공유.

### 수정

| 파일 | 변경 내용 |
|---|---|
| `src/app/globals.css` | body `overflow-x: clip` → `overflow: hidden`. html `scrollbar-gutter: stable` 제거. `html body[data-scroll-locked] { margin-right: 0 !important }` 블록 제거 (더 이상 불필요). |
| `src/app/layout.tsx` | body className `min-h-full` → `h-full` (body가 뷰포트를 꽉 채워야 스크롤이 #scroll-root로 위임됨). |
| `src/components/common/GlobalLayout.tsx` | `ScrollContext.Provider` + `#scroll-root` div 추가 (`h-full overflow-y-auto flex flex-col`, `scrollbar-gutter: stable`). `useEffect`로 pathname 변경 시 `scrollRef.current.scrollTo(0,0)` 호출 (Next.js의 `window.scrollTo` 대체). |
| `src/components/common/Header.tsx` | `window.scrollY` → `container.scrollTop`, `window.addEventListener("scroll")` → `container.addEventListener("scroll")`. `useScrollContainer()` 사용. |
| `src/components/common/ScrollToTop.tsx` | 동일하게 `window.scroll*` → `container.scroll*`. `useScrollContainer()` 사용. |
| `src/hooks/useCreateJobForm.ts` | `window.scrollTo(0, 0)` 2곳 → `document.getElementById("scroll-root")?.scrollTo(0, 0)`. |
| `src/utils/lockScroll.ts` | `document.body` 대신 `document.getElementById("scroll-root")` 타겟. body 는 이미 overflow:hidden이라 의미 없고, 실제 스크롤은 #scroll-root에서 일어남. scrollbarWidth 측정 후 paddingRight 보상 로직 유지. |

## select.tsx 추가 수정 (UI)

- `SelectTrigger`: `active:scale-100` 추가 (전역 active:scale-[1.05] 억제)
- `SelectContent`: `side="bottom"` 고정, `min-w-32 max-w-64` 폭 제한, `w-[var(--radix-select-trigger-width)]` 제거
- `SelectPrimitive.Viewport`: `min-w-(--radix-select-trigger-width)` 제거

## lockScroll 동작 원리 (변경 후)

```
모달 열릴 때:
  container.offsetWidth - container.clientWidth → 스크롤바 폭 측정
  container.style.overflow = "hidden" → #scroll-root 스크롤 잠금
  container.style.paddingRight = "${scrollbarWidth}px" → 스크롤바 사라진 만큼 보상

모달 닫힐 때:
  container.style.overflow = "" → 잠금 해제
  container.style.paddingRight = "" → 보상 제거
```

## 기존 window.scroll 사용처 처리

| 위치 | 처리 방법 |
|---|---|
| Header.tsx (scroll 감지) | `useScrollContainer()` ref → `container.scrollTop` |
| ScrollToTop.tsx | `useScrollContainer()` ref |
| useCreateJobForm.ts (step 전환) | `getElementById("scroll-root")` (hook이라 context 사용 불가) |
| Next.js 라우팅 scroll restoration | GlobalLayout의 `useEffect([pathname])` |
