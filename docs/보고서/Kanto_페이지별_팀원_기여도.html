METHODOLOGY

산정 기준 및 해석 방법

01. 근거 자료

페이지·핵심 컴포넌트·서비스 파일의 최초 작성자와 이후 코드 계보, 최종 코드에 남은 기능 범위를 확인했습니다.

02. 비율 산정

페이지의 기반을 처음 만든 사람에게 가장 높은 기본 기여도를 부여하고, 이후 기능 확장·디자인·개선의 실제 작성 범위를 보조 반영했습니다.

03. 항목 정의

  • 기능 구현: 신규 기능·데이터 연동
  • 디자인/UI: 레이아웃·반응형·접근성
  • 추가 개선: 버그·성능·리팩터링·보안

제외 기준

커밋 개수와 WBS는 정확한 기여도를 보여주지 못한다고 판단해 산정에서 완전히 제외했습니다.

공통 작업 배분

헤더, 국제화, 검색·필터 등은 최초 구현자와 해당 페이지에 실제 남은 코드의 영향 범위를 기준으로 반영했습니다.

원형 차트

우측 차트는 해당 페이지의 세 항목을 종합한 기여도입니다. 좌측에는 항목별 팀원 비율을 별도로 표시했습니다.
