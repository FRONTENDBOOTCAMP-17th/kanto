### 🚨 모바일이 개선되지 않음 — TBT는 오히려 4배 가까이 악화

이 페이지는 "Google Maps SDK를 `next/dynamic`으로 지연 로딩해서 초기 번들에서 제거"하는 개선이 **완료**로 표기돼 있는데, 재측정 결과 **모바일 TBT가 480ms → 1999ms로 오히려 크게 나빠졌고 LCP도 8.1s → 8.96s로 개선되지 않았다.** 두 측정(9.26s/8.66s, 1807ms/2191ms)이 서로 근접해 노이즈로 보기 어렵다 — **이 개선이 실제로 배포된 빌드에 반영됐는지, 또는 지연 로딩이 의도대로 동작하는지 코드/배포 상태를 다시 확인해야 한다.**

**🖥️ 데스크탑은 LCP만 뚜렷이 개선**(2.1s 🟡 → 0.73s 🟢), TBT·SI는 큰 변화 없음.

3. 데스크탑 LCP 개선은 확인됨(2.1s→0.73s) — 모바일만 원인 파악 필요
