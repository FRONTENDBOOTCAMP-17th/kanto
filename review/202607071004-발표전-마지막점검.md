# 발표 전날, 마지막으로 이것만 챙깁시다 (Kanto)

전체적으로 안정적으로 마무리돼 가고 있습니다. 오늘은 새 기능을 붙이기보다, 공개·배포 순간에 조용히 문제가 될 만한 곳 두 가지와 데모 리허설만 챙기면 좋겠습니다.

- 금칙어 검사가 지금은 화면(클라이언트) 쪽에서만 걸러지는 구조라, 스크립트로 곧장 서버에 넣으면 통과할 수 있습니다. 게시글을 실제로 저장하는 서버 경로에서도 한 번 더 검사하도록 막아두면 안심입니다.

- 손으로 걸어둔 개인정보 차단을 마이그레이션으로 옮긴 건 좋았는데, 완전히 빈 상태에서 마이그레이션을 처음부터 적용했을 때 목록·채팅이 정상으로 뜨는지 한 번만 확인해 보세요. 새 환경에 배포할 때 그대로 재현되는지가 마지막 관문입니다.

- 실시간 채팅이 이 서비스의 핵심이니, 발표 때 계정 두 개로 메시지가 오가는 흐름을 미리 한 번 돌려보고, 배포본이 최신 코드인지도 확인하고 가면 됩니다.
